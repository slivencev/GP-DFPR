# GP-DFPR

**Goal-Preserving Network Reconfiguration under Partial Observability and Execution Delays**

Serhii Liventsev · Igor Sikorsky Kyiv Polytechnic Institute · ORCID: [0000-0002-9768-8133](https://orcid.org/0000-0002-9768-8133)

This repository contains **50 original source-package files** across six archived study stages (v3, v9, v11, v12, v14 and v15), including the original v15 GPL-2.0 source license and v12 replay contexts. The imported bytes were verified against the author's original Supplementary Data S2 SHA-256 checksum before the automated import. The import manifest is [IMPORT_SHA256.json](IMPORT_SHA256.json).

Research archive cited by the manuscript: [Zenodo 10.5281/zenodo.22893667](https://doi.org/10.5281/zenodo.22893667), version 1.0.0.

**Scope:** The manuscript reports synthetic experiments with conditional guarantees, not an independently validated deployed O-RAN controller. The authentic v8 predecessor was subsequently recovered from the author, its hash matched the historical v9 checkpoint, and the full synthetic v9 computation was rerun with four archived CSV outputs byte-identical. The original v8 binary is stored separately from this GitHub source checkout. The original bulk traces and historical complete ZIP archives remain associated with Supplementary Data S2 rather than being duplicated into GitHub.
