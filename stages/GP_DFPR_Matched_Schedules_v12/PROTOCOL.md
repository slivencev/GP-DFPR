# v12: matched-cache, matched-availability acquisition comparison

Fixed before execution, 2026-09-20. Use saved v9 environments, durations 12/36, budgets 4/8, delay multipliers 1/2, runs 6000..6011. These are existing data, not independent validation. Both Pure-sweep and Uncovered-first generate reference trajectories: 192 reference runs. Using both origins avoids relying on only one policy's initial cache and execution mask.

For each actually empty episode in each reference trajectory, save the reference cache immediately before its first step's queries, propagated to the episode start. Save acquisition pointer and last-query times. All compared schedules receive identical copies. Reference decision instants define the common allowed query times; pending execution means no query capacity. Reference current-action IDs at those instants are also fixed and shared.

Replay Pure-sweep and Uncovered-first as acquisition rules inside this fixed context, retaining their actual stopping rules and budget. Their proposed actions are NOT executed: reference action path and blackouts are held fixed. Consequently this compares information acquisition under a fixed execution context, not closed-loop GPR or a deployable alternative control trajectory. Clone reference internal acquisition state for both schedules; do not give either a freshly reset cyclic pointer. Every episode restarts from its own reference state; alternative schedules do not carry modified state into later episodes.

For each target T in the episode, the exact retrospective matcher uses the SAME initial cache, the SAME available times up to T, SAME budget, and SAME realized measurement outcomes. Alternatives whose initial cached upper witness survives to T need no query. An edge from a remaining alternative to a slot at s exists iff min_i[z_i(a,s)+eta+L*(T−s)]<0. Initial intervals and query intervals intersect coordinatewise; any negative resulting upper bound must originate from an initial witness or one queried witness, so this matching formulation is exact for fixed T and this interval model.

The matcher knows future query outcomes and can omit online early stopping; its per-target feasibility is a conditional upper bound on certificate detection by either replayed acquisition rule in the fixed context. It does not certify that a single schedule can attain all feasible targets simultaneously. It is not a bound on other initial states, execution paths or richer models. Online rules never receive future outcomes or the true episode end.

Primary metrics: online empty-step recall and fraction of per-target oracle attainability, all with common denominators; gap in attainable-but-undetected steps; missed episodes and restricted first-detection wait. Record query counts. Report both reference origins separately. No GPR claims and no inference of causality from an oracle gap. Aggregate by independent source run; repeated episodes, reference origins and targets share data.

Validation: compare replay of the reference policy with its original cached upper bounds at every allowed step; assert any online certificate implies oracle attainability; validate every oracle witness, capacity and blackout constraint; keep reference simulator invariants. Test cache-only feasibility, blocked slots and strict expiry. Verify v11 archive and preserve all previous outputs. Save initial contexts, target-level results, paired intervals and source traces.
