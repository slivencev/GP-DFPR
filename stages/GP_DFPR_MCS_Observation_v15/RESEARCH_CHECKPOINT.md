# Контрольная точка v15

Архив v14 проверен, прежние результаты сохранены. Сделан узкий эксперимент для MCS 4/10/15 на одном наблюдаемом канале: один общий отчёт SINR поддерживает три оценки, возраст включает доставку и горизонт исполнения. Истина альтернатив не передаётся предиктору.

30 синтетических траекторий; 1620 комбинаций предиктор/условия; 644760 проверок включения при соблюдении предположений. Преднамеренное превышение границы модельного сдвига создаёт ложные допуски. Это ожидаемый отрицательный контроль, не основание подгонять запас после результата.

Большая часть интервалов выходит за опубликованные диапазоны узлов выбранных кривых. Поэтому общая модель наблюдения реализована, но пригодность её жёстких границ для реальной RAN не доказана. Предиктор и оценщик используют один компонентный источник; packet-level simulator не запускался.

Следующее необходимое действие: внешняя проверка области и ошибки модели на согласованном action space или независимой физической реализации. Не продолжать объявлять нулевые ошибки внутри той же модели внешней валидацией. Бюджет наблюдений учитывать по общим физическим измерениям, а не по числу производных альтернатив; прежняя модель matching с отдельным запросом каждой альтернативы автоматически не переносится на пакетные свидетельства.
