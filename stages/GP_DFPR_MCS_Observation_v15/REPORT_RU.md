# Измерение общего канала и оценка нескольких MCS: v15

## Научный результат

Реализован общий источник наблюдения вместо независимого шумного доступа к истинным KPI каждой альтернативы. Предиктор получает только SINR, момент измерения и параметры ошибки. Это более содержательная модель наблюдения, однако сигнал SINR всё ещё синтетический, а предиктор и оценщик используют одну и ту же компонентную аппроксимацию.

При совпадении модели интервалы не дают ложных допусков, как и следует из заданных ограничений. При сдвиге 0,35 дБ и учёте только ошибки датчика появляются 1262 ложных допуска из 93098 (1,36%). Добавление явно принятого запаса модельного сдвига 0,4 дБ устраняет их в этом случае. При реальном сдвиге 0,70 дБ этот запас уже недостаточен: 877 из 86445 допусков ошибочны (1,01%). Запас 0,4 дБ — параметр контролируемого опыта, а не оценённая ошибка реального оборудования.

Существенное ограничение: полностью внутри диапазонов опубликованных узлов лежат лишь 6,87% интервалов Interval и 1,27% Interval-plus-model. Остальные используют заданные плато за пределами таблиц. Поэтому нулевую ошибку в согласованной модели нельзя представлять как эмпирическое доказательство реальной безопасности. Если требовать только табличную область применимости, остальные случаи должны получать UNKNOWN; такая проверка области показана отдельно и не применялась задним числом к приведённым допускам.

Для следующего этапа нужна независимая физическая проверка или более полный набор результатов с явно обоснованной областью интерполяции. До этого готовый результат — воспроизводимый тракт общей телеметрии, корректное распространение условных ошибок и демонстрация разрушения гарантий при выходе за предположения. Это не внешняя валидация неактивных конфигураций.

Проверен тракт «одна шумная оценка SINR → интервалы для MCS 4/10/15». Истина альтернатив доступна только оценщику. Это эксперимент с компонентной аппроксимацией, не запуск ns-3 или проверка реальной RAN.
